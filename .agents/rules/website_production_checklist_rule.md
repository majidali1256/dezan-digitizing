# Mandatory 20-Point Website Production & Launch Checklist

Whenever building, modifying, reviewing, or finalizing ANY website or web application project, the AI agent MUST automatically create, implement, or proactively suggest all 20 of the following essential production files and standards:

## The 20 Essential Website Standards:
1. **Privacy Policy Page (`privacy.html` or `/privacy`)**: Data collection, cookie disclosures, GDPR/CCPA rights, contact info.
2. **Terms of Service Page (`terms.html` or `/terms`)**: Commercial service clauses, intellectual property, refunds, liability.
3. **Clear High-Converting CTAs**: Prominent primary action buttons with high contrast across heroes, headers, and pricing.
4. **Interactive FAQs**: Structured accordion or collapsible questions addressing buyer objections.
5. **`robots.txt`**: Explicit crawler guidance allowing public marketing routes and disallowing private portals, workspaces, or APIs, with `Sitemap:` pointer.
6. **`sitemap.xml`**: Valid XML schema listing all public URLs with `changefreq`, `priority`, and `lastmod`.
7. **Custom 404 Error Page (`404.html`)**: On-brand, beautifully styled error screen guiding users back to Home or Key Services with zero dead-ends.
8. **Descriptive Image Alt Text**: Comprehensive keyword-rich `alt` and `title` tags on all photos, mockups, and icons for SEO and screen readers.
9. **Web Analytics Integration**: Google Analytics 4 (GA4) or privacy-friendly tracking module ready with flexible Measurement ID injection.
10. **Descriptive Meta Titles**: Unique, keyword-optimized `<title>` tags on every single page.
11. **Compelling Meta Descriptions**: Curated `<meta name="description">` tags on every page for high Google search CTR.
12. **Social Share Metadata**: Full Open Graph (`og:*`) and Twitter Card (`twitter:*`) tags for rich social media link previews.
13. **Favicon & Brand Icons**: [favicon.ico](file:///Users/macbookair/VS%20CODE%20PROJECTS/DEZAN%20Desitizing/favicon.ico) and apple-touch-icon links in `<head>`.
14. **Canonical URIs**: Authoritative `<link rel="canonical">` tags on all pages to prevent duplicate content penalties.
15. **Cookie & Privacy Consent Banner**: Lightweight, accessible, floating banner providing essential vs tracking choices adhering to GDPR/CCPA.
16. **Responsive Mobile Version**: Strict multi-viewport support (Desktop, Tablet, 390px & 360px Mobile) with touch targets $\ge 44$px and zero horizontal overflow.
17. **WCAG 2.1 AA Accessibility**: High-contrast text ($\ge 4.5:1$ light and dark), ARIA attributes, semantic HTML, and keyboard navigation.
18. **End-to-End Tested Forms**: Validated inputs, accessible labels, clear submission feedback, and error handling.
19. **Broken Link & Asset Verification**: Zero broken internal links, zero missing anchors, and zero broken image paths (`naturalWidth > 0`).
20. **Performance Optimization & Universal WebP Images**: Every picture must be in `.webp` format for rapid page loads without quality loss. Zero CLS (layout shifts), explicit image dimensions, asset preloading, native lazy-loading, and fast lightweight execution.

Always audit existing projects against this checklist and supply any missing files immediately.
